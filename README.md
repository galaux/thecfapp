# TheCFApp

This Git repository is a monorepo that leverages Yarn's workspaces as per the
following file hierarchy:

```
.
├── api
│   ├── src
│   │   └── …
│   ├── package.json
│   └── yarn.lock
├── front
│   ├── src
│   │   └── …
│   ├── package.json
│   └── yarn.lock
├── package.json
└── yarn.lock
```

The _root_ `package.json` is an empty shell used to declare workspaces `api`
and `front` as well as root level Yarn scripts.

The `./front` folder holds project files for the front-end webapp which build
output is a set of static files. See [README.md](./front/README.md) for more
information.

The `./api` folder holds project files for the back-end API which build output
is an [NodeJS Express](https://expressjs.com/) application that serves the
[GraphQL](https://graphql.org/) API as well as the static files generated by
the front-end. See [README.md](./api/README.md) for more information.

## Scripts

### Launch both back-end and front-end

```
yarn build && yarn start
```

### Launch the front-end only

This will build and launch the front-end in a standalone HTTP server with file
watch.

```
cd front
yarn install
yarn start
```

### Launch the back-end API only

This will build and launch the back-end application in a standalone HTTP server
without trying to serve the front-end static files.

```
cd api
yarn install
cp .env.example .env
yarn dev
```
